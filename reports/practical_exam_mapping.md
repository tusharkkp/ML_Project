## 2. Complete Syllabus Algorithm Coverage Checklist (`ML_algos.txt`)

Every algorithm listed in `ML_algos.txt` is fully implemented and tested in [`scripts/train_all_models.py`](file:///c:/Users/Tushar%20Kaldate/Documents/ML_Project/scripts/train_all_models.py):

### A. Regression

- [x] **Simple Linear Regression**: Univariate baseline ($P_{t-1} \to P_{t+1}$), produces closed-form line equation.
- [x] **Multiple Linear Regression**: Standardized OLS using all 15 econometric and supply features.
- [x] **Polynomial Regression**: Degree-2 polynomial feature mapping with regularized interaction terms.
- [x] **Ridge Regression ($L_2$)**: Tikhonov regularized shrinkage handling collinear time-series lags.
- [x] **Lasso Regression ($L_1$)**: Sparse shrinkage performing automated feature selection.

### B. Classification (Price Spike & Inflation Shock Detection)

- [x] **Logistic Regression**: Baseline linear probabilistic classifier with balanced class weighting.
- [x] **Naive Bayes**: Gaussian Naive Bayes modeling conditional price momentum distributions.
- [x] **KNN (K-Nearest Neighbors)**: Non-parametric neighbor voting based on standardized feature distance.
- [x] **Decision Tree (CART)**: Gini-impurity splitting tree generating interpretable market crisis rules.
- [x] **SVM (Support Vector Machine)**: Soft-margin hyperplane with Radial Basis Function (RBF) kernel.

### C. Ensemble Learning

- [x] **Bagging**: Bagging Regressor and Bagging Classifier using bootstrap aggregation.
- [x] **Boosting / AdaBoost**: Sequential adaptive re-weighting focusing on hard supply-shock samples.
- [x] **Stacking**: Stacking Regressor and Stacking Classifier with meta-learner estimators.
- [x] **Voting Classifier / Regressor**: Soft-voting consensus across heterogeneous base learners.

### D. Clustering & Unsupervised Learning

- [x] **K-Means**: $k$-means clustering with Elbow Method and Silhouette Analysis identifying market regimes.
- [x] **Hierarchical Clustering**: Agglomerative clustering with Ward linkage and hierarchical dendrogram visualization.
- [x] **Density-Based Clustering (DBSCAN)**: Epsilon-neighborhood clustering isolating anomalous market trading days.

### E. Dimensionality Reduction

- [x] **PCA (Principal Component Analysis)**: Eigen-decomposition extracting orthogonal principal components with Scree Plot.

### F. Optimization Algorithms

- [x] **Gradient Descent (Batch GD)**: Full-batch parameter updates displaying smooth MSE convergence.
- [x] **Stochastic Gradient Descent (SGD)**: Single-sample parameter updates displaying stochastic path exploration.
- [x] **Mini-batch Gradient Descent**: Balanced batch-size updates ($N=32$) combining computational speed with stability.
